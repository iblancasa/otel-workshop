## Before you arrive

Do this at home, on real wifi. It takes 5 to 15 minutes and needs Docker, kind and kubectl.

```bash
git clone https://github.com/iblancasa/otel-workshop.git
cd otel-workshop/otelite      # or otel-workshop/cncf
make prepare
```

## The system

```
browser / loadgen
      |
      v
 frontend (Node.js)  --->  orders (Python)  --->  inventory (Java)
                             |     |
                             |     '-->  payments (Python)
                             '-->  "warehouse" (legacy client, simulated)

 every service  --OTLP-->  OpenTelemetry Collector  --OTLP-->  the backend(s)
```

| | otelite flavour | CNCF flavour |
|---|---|---|
| traces | [otelite](https://github.com/planetf1/otelite) | [Jaeger](https://www.jaegertracing.io/) |
| metrics | otelite | [Prometheus](https://prometheus.io/) |
| logs | otelite | [Loki](https://grafana.com/oss/loki/) |
| dashboards | otelite | [Perses](https://perses.dev/) |
| Collector config | three processors to work around otelite's limits | none, two connectors to derive metrics from traces |
| memory | under 100 MB | about 1 GB |
