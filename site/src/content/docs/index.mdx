## Before you arrive

Do this at home, on real wifi. It takes 5 to 15 minutes and needs Docker, kind and kubectl.

```bash
git clone https://github.com/iblancasa/otel-workshop.git && cd otel-workshop
make prepare
```

## The system

```
browser / loadgen
      |
      v
 frontend (Node.js)  --->  orders (Python)  --->  inventory (Java)
                             |     |
                             |     '-->  payments (Python)
                             '-->  "warehouse" (legacy client, simulated)

 every service  --OTLP-->  OpenTelemetry Collector  --OTLP-->  otelite
```

Backend is [otelite](https://github.com/planetf1/otelite): a single binary that receives OTLP and shows logs, traces and metrics in one dashboard. Under 100 MB of memory, so every laptop in the room can run it.
